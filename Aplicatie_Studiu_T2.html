1. Scoruri de Specificitate (de la cel mai mare la cel mai mic)

Ordinea de evaluare în CSS Cascade: 1) Importance (!important) & Origin → 2) Specificity → 3) Order (ultima declarație câștigă) → 4) Inheritance. Dacă proprietățile nu intră în conflict, are loc Declarations Merge.

2. Containing Block în funcție de position

Valoarea position Cum este determinat Containing Block Scoate din normal flow?
static De regulă, prin zona de conținut a celui mai apropiat strămoș care este container bloc Nu (implicit)
relative Similar cu static (se mută vizual față de normal flow, dar păstrează spațiul ocupat) Nu
sticky Similar cu static Nu (hibrid la scroll)
absolute De regulă, prin zona de padding a celui mai apropiat strămoș poziționat (position != static; implicit <html>) Da
fixed În mod obișnuit, viewport-ul (rămâne în aceeași poziție la derularea paginii) Da

3. Regula Cromatică 60-30-10 în UI Design

60% Main (Fundal)
30% Secondary
10% CTA

60% Main (fundaluri și suprafețe extinse — unitate vizuală) • 30% Secondary (componente secundare, texte, pictograme) • 10% Accent (butoane CTA și puncte cheie de interes). Notă: Proporțiile sunt orientative, nu obligatorii — contrastul și accesibilitatea primează întotdeauna!

4. Numere, Formule & Reguli-Cheie pentru Examen

Box Model (content-box)

Lățime totală = width + padding-L + padding-R + border-L + border-R
outline și box-shadow NU modifică dimensiunea casetei. Marginile verticale pozitive adiacente colapsează la max().

Unități & Tipografie

Default browser font-size: 16px.
em = desired_px / parent_px (se compune la imbricare) | rem = față de <html>.
Folosiți cel mult 3 tipuri de font! line-height: 1.5 pe 16px = casetă rând de 24px.

Grid Responsive 12 Coloane

1 col = 100% / 12 = 8.33%
col-3 = 25% • col-4 = 33.33% • col-6 = 50% • col-12 = 100%.
Nu suprapuneți intervalele în @media (ex. min-width: 1200px și max-width: 1199px).

Culori (HSL, RGB, Keywords)

RGB: 0–255 | Alpha: 0 transparent, 1 opac.
HSL: 0° Roșu, 120° Verde, 240° Albastru; Lightness 0% Negru, 50% Normal, 100% Alb.
Capcană: darkgray este mai deschis decât gray!

Legea lui Fitts (UI)

MT = a + b · log2(2DW)

Timpul MT crește cu distanța D și scade cu lățimea țintei W (Big and near objects are easy to click).

Metrici UX & Landing Page

~50 ms: formarea primei impresii vizuale (Lindgaard et al., 2006).
53% dintre vizitatorii de pe mobil părăsesc pagina dacă încărcarea durează > 3 secunde.
Above the fold: Titlu + CTA + Hero.
